# Played-map outcome diagnostic — 2026-09-25

Protocol fixed before running in [`map-outcome-protocol-2026-09-25.md`](map-outcome-protocol-2026-09-25.md). Run `python scripts/map_outcome_diagnostic.py` on the dev DB snapshot. The baseline is the production K=48 map-share Elo replay (whole-series probability inverted to independent map probability), not a claim that production emits per-map prices. The candidate is the previously frozen `features/maps.py` optional known-veto model at map K=8, prior=160. All maps of one series are forecast before any map-specific update from that series. The diagnostic conditions on the **played map name observed retrospectively**; no recorded pre-series veto timestamp or unplayed decider is available.

- **2023–24 validation:** 1,934 maps in 765 Tier-1 series. Baseline log loss **0.66625**, candidate **0.66619**; both Brier **0.23674** to five decimals. Paired map t=**+0.15**, paired series-mean t=**−0.79**. This is not a useful validation gain, despite a tiny map-weighted improvement.
- **2025 retrospective:** 1,272 maps / 498 series. Baseline **0.67581**, candidate **0.67516**; Brier **0.24148** vs **0.24116**; map t=**+1.30**, series-mean t=**+0.67**.
- **2026 retrospective:** 934 maps / 360 series. Baseline **0.67200**, candidate **0.67167**; Brier **0.23968** vs **0.23954**; map t=**+0.61**, series-mean t=**+0.10**.
- **2025–26 pooled retrospective:** 2,206 maps / 858 series. Baseline **0.67420**, candidate **0.67368**; Brier **0.24071** vs **0.24047**; map t=**+1.40**, series-mean t=**+0.57**. Only 2,023/2,206 scored maps had at least one prior result for *both* teams on that map.

Paired map t treats maps as independent; the series-mean t averages each series' map-level loss differences and is the more conservative dependence check (it is *not* a map-weighted cluster-robust standard error). Both fall far short of the >2 threshold. The protocol's conditional 2025–26 step was run because validation map-weighted loss was marginally lower; the validation series-mean difference had the opposite sign. **Verdict: reject the existing map adjustment as evidence for a pre-veto forecasting change.** Do not tune K/prior to these retrospectively consulted years. No primary forecast change or live DB/raw write. A future series model still requires timestamped *full* pre-start veto observations, especially unplayed deciders.
