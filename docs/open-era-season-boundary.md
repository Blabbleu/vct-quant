# 2027 LCQ season boundary (candidate, disabled)

The [Riot 2027 format](https://valorantesports.com/news/get-ready-for-vct-2027-open-qualifiers) places South Asia/Oceania on an open Pacific LCQ/Wild Card path; [November 2026 qualifiers](https://valorantesports.com/news/no-guaranteed-paths-inside-the-new-vct-2027) feed the 2027 Kickoff. Vlr.gg's actual 2027 event titles have **not** been observed yet. Examples below are provisional, not source-verified names.

The current `competition_tier(title, year)` prioritizes its `year` argument over the season in the title. For a November 2026 fixture titled `VCT 2027: Pacific LCQ`, `official_upcoming` passes 2026, labels it Tier 1 and emits a primary forecast. `_classify_stored_events` likewise passes `dates_raw=2026`, feeding its completed results into Tier-1 ratings. Without a supplied year, the same title is Tier 2. A `Champions Tour 2027: ... LCQ` title also passed through the historical Tier-1 branch before the LCQ rule.

`OPEN_ERA_TITLE_SEASON` is a **disabled** candidate flag in `etl/events.py`. If enabled, an explicit title season takes precedence over calendar year; 2027 official LCQs become Tier 2, while explicitly 2026 LCQs remain Tier 1 even if observed in 2027. The long `Champions Tour 2027: ... Open Qualifiers` prefix also needs this gate: without it, the historical branch labels the hypothetical open stage Tier 1. The candidate labels it Tier 2, preserves pre-2027 `Champions Tour` scope, and remains off by default. These are synthetic names, not verified vlr.gg titles. Tests cover the classifier, upcoming-feed exclusion, and stored-event reclassification. Nothing in primary forecasts changes while the flag is false.

The dev DB snapshot has **2,215 events and zero tier differences** under the candidate; `scripts/benchmark_elo.py` remains 0.6567 log loss on 1,676 matches. This is **not** a retrospective model win or a promotion case. Before activation, verify real vlr.gg titles and the Riot stage mapping, test with a captured actual feed/event payload, and request explicit approval because switching the flag changes which matches enter Tier-1 ratings and primary forecasts. The live checkout, raw data and model settings are untouched.

The read-only audit evaluates both scopes explicitly without flipping the global flag. `candidate_scope_changes` lists fixtures whose calendar-year classification would change with the title-season override; a failed upcoming feed gives `null`, not an empty list. `candidate_tier_if_2026` is hypothetical, while `candidate_tier_by_title` works from the title alone. This catches long-prefix `Champions Tour 2027: ... LCQ` fixtures: the old `calendar_tier_mismatches` list is empty because *both* current calendar and current title-only paths give Tier 1, but the candidate makes them Tier 2. The override keyword is audit-only; production calls retain the default disabled flag.

The September 18 archived capture also contains 40 consecutive event pages (2,026 rows); a read-only replay with the September 25 04:15 UTC 18-fixture cache passed pagination checks and likewise found only non-VCT `Esports Nations Cup 2027` (event 3008), with zero candidate scope changes. This is broader **historical** coverage, not a current negative observation; the two inputs are from different times and the live source still fails.

The report lists `event_pages_checked`; `complete` means the **requested** pages and feed succeeded, not that every event on vlr.gg was searched. Any failed requested page causes a nonzero exit and `complete: false`; an identical nonempty page returned for a later page number is likewise rejected as a pagination failure rather than double-counted (repeated empty tail pages are allowed). Malformed success envelopes also fail instead of becoming empty evidence. The nine-page Sep 18 archive replay still checks all 476 distinct rows after this guard.
