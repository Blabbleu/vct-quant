## 2. The fast/slow ensemble

This is a logit-space blend of two Elo ratings: a slow one (K≈16) that tracks organisation strength, and a fast one (K≈128–256) that reacts to current form.

- **Wins every walk-forward fold** (benchmark_elo protocol): pooled **0.6488 vs 0.6567** log loss, Brier 0.2285 vs 0.2320, accuracy 62.6% vs 61.6%.
- **Broad plateau, not a spike:** 82% of the 330 nearby settings improve on held-out data, with median t = +1.60.
- **But no single pre-selected setting clears t > 2 in both years.** The round-2 pick (0.6·K16 + 0.4·K128) reached t = +2.99 held-out. The wider grid's validation pick reached only t = +1.70, and 2026 alone is t = +0.69.
- Calibration is still overconfident at 60–80%, the same pattern as raw Elo.

**Recommendation:** run the ensemble in shadow. Log its probability next to Elo in `prediction_log.parquet` and let `grade_predictions.py` score it on live matches. Promote it only under the rule in section 3, which was fixed before any shadow forecast was graded.

## 3. Promotion rule for the fast/slow ensemble (fixed 2026-09-24, before any shadow was graded)

**The score.** Mean log loss of the ensemble minus Elo, on the matches listed in the "fast/slow ensemble" section of `python scripts/grade_predictions.py`. That section covers official-pool matches whose last pre-start forecast carried both probabilities. Lower is better.

**Checkpoint 1: after the Valorant Champions 2026 grand final is graded.**
- If n ≥ 25 and the ensemble's live log loss is **no worse than Elo's** (difference ≤ 0.0000), promote it.
- Otherwise, keep Elo and continue to checkpoint 2.
- If fewer than 25 matches were graded, skip to checkpoint 2.

**Checkpoint 2: at 300 graded matches (about the 2027 season).**
- Same test for a model that wasn't promoted: promote if it's no worse than Elo.
- For a model that was promoted: demote it if it's worse than Elo by more than 0.01.

**Promotion means:** `p_team_a_win` becomes the ensemble. Raw Elo keeps being logged as `p_team_a_win_elo`, so checkpoint 2 can still compare the two.

**The online shrink is not eligible at checkpoint 1**, because its backtest evidence is weaker (t = +1.21). It is judged at checkpoint 2 by the same rule, and only if the ensemble was not promoted. Only one model changes at a time.

**What the rule can and cannot tell us.** I resampled the real 2025–26 per-match differences (n = 1,094, sd 0.132 per match) to see how the rule behaves:

| Graded matches | Standard error | Passes if the backtest gain is real (+0.0068) | Passes if the ensemble is actually 0.02 worse |
|---:|---:|---:|---:|
| 35 (Champions) | 0.022 | 62% | 19% |
| 300 | 0.008 | 82% | ~0% |

Checkpoint 1 is a weak filter. Its job is to catch a clear regression. The case for promoting rests on the backtest: all 5 walk-forward folds, and a broad plateau of good settings.
Checkpoint 2 has real power in both directions.
**Do not change this rule, the thresholds or the ensemble weights after seeing live results.**

## 4. Rejected ideas: what we learned

- **Best-of-aware ratings hurt badly.** Treating ratings as per-map strength and compounding them to a series probability makes favourites far too confident, and a wider scale did not fix it.
- **Inactivity decay and player-level Elo** add nothing beyond what K=48 already learns.
- **Refitting a logistic layer on Elo alone lost in every setting that finished.** The versions with player form, churn and experience were never scored. The mapping from rating to probability drifts across eras (see the calibration notes in CLAUDE.md), so fitting on past years hurts.
