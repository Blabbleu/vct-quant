# Daily batch Bradley–Terry refit

## Pre-registration

Hypothesis: global refitting can use transitive information acquired after earlier matches and improve future forecasts over production online Elo. Replay the official Tier-1 and Tier-2 `match_sequence` in match ID order. Give each match its UTC completion day; forward fill missing completion dates from the preceding match. Before any forecast on day D, fit only matches dated strictly before D. For runtime, refit on three-day UTC buckets, using matches strictly before each bucket's first day; this makes some forecasts use less recent data than a daily refit. No production code changes.

Model: no-intercept logistic Bradley–Terry, probability `sigmoid(s_a - s_b)`. Weight each past series by `0.5 ** (age_days / half_life)` and penalize `lambda * sum(s**2)`. Series mode uses one binary result per non-draw series. Maps mode uses scored maps as binomial successes; series without map score fall back to its binary result. Teams without prior matches have strength zero. Forecast scale is one. Also score a fixed 50/50 blend of the Elo and BT logits. Elo comes from the official `compute_elo` replay with `margin_signal` and `elo_k`.

Grid: half-life 90, 180, 365, 730 days; lambda 0.1, 1, 10; mode series or maps (24 cells). Select minimum mean Tier-1 binary-series log loss over the combined 2023 and 2024 walk-forward forecasts, without using 2025 or 2026 for selection. Log loss is primary; Brier, accuracy, 10-bin reliability, and ECE are secondary. Freeze the chosen cell and report 2025 and 2026 separately on the same Tier-1 binary matches as Elo. Report paired t from per-match Elo loss minus candidate loss.

Apply the following rule separately to pure BT and the blend: **WIN** iff paired t > +2 and ECE <= Elo ECE in both test years; **NOT PROVEN** if both t statistics are positive but the WIN condition fails; otherwise **REJECTED**. Earlier experiments have already consulted 2025 and 2026, so these are not untouched holdouts.

### Verdict

**Pure BT: REJECTED.** Its paired t is negative in both 2025 (−2.089) and 2026 (−1.282), so it fails the pre-registered rule.

**50/50 logit blend: REJECTED.** Its paired t is negative in 2025 (−0.651), despite a small positive 2026 result (+0.278); the rule requires positive t in both years even for NOT PROVEN.

The batch fit did not beat production Elo on the frozen test years. These years had already been consulted by earlier experiments, so this result is retrospective evidence rather than a clean prospective validation. The experiment remains shadow only.
